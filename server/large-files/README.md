# Большие вложения

Этот набор соответствует API Fluxer 2026.1015.51512. Патч `upload-part-size.patch` ограничивает части загрузки 64 МиБ. Для сохранённого `AppEntrypoint.js` после этой правки SHA-256 равен `cbdc9436783e9b1a12a8b20cfc2daf746a54f83422553ad611bdd262c4090981`. Примените `git -c core.autocrlf=false apply publication-delay.patch` к этому файлу и используйте Dockerfile для сборки поверх образа с лимитом 64 МиБ.

Итоговый SHA-256 AppEntrypoint.js — e84c9d75dd6ca8ce2a160fbe1874a300606f73400ab561744cb4b7a7f1fabd05. Правки убирают временную копию для обычных вложений, сохраняют антивирусную обработку и ускоряют межбакетное копирование.
