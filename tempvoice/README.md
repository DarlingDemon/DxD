# DxD TempVoice

Отдельный бот для временных голосовых комнат Fluxer. Пользователь входит в «➕ Создать комнату», бот создаёт голосовой канал в той же категории и перемещает туда это подключение. Когда из комнаты выходят все участники, бот удаляет её через 15 секунд. Список созданных комнат сохраняется на диске, а перед уборкой после перезапуска бот дожидается снимка голосовых подключений.

- `!room name Название` меняет название своей комнаты.
- `!room limit 0–99` задаёт лимит участников. `0` снимает лимит.
- `!room claim` передаёт комнату её текущему участнику, если владелец вышел.

## Развёртывание

1. Создайте приложение-бота в DxD и добавьте его в нужное сообщество.
2. Создайте отдельную категорию и голосовой канал входа внутри неё. Дайте боту в категории права просмотра, подключения, управления каналами и перемещения участников. Права на чтение и отправку сообщений нужны в текстовом канале, где будут использоваться `!room`.
3. Укажите `TEMPVOICE_GUILD_ID` и `TEMPVOICE_CREATOR_ID` в `.env`. Сохраните токен в `secrets/bot-token` и предоставьте UID 1000 право чтения этого файла. Каталог `data` должен быть доступен UID 1000 на запись.
4. Выполните `docker compose up -d --build`. В журнале должна появиться строка `Creator channel verified, gateway ready`.

Источник идеи — [документация TempVoice](https://github.com/TempVoice/Documentation).
